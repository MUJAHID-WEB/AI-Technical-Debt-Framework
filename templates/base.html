About the Framework
The Core Problem

When we add AI components to our systems, they introduce a new, sticky kind of technical debt. Unlike traditional code debt, AI debt includes:

  • Hidden feedback loops where models influence their own training data
  • Explosive glue code connecting components
  • Undeclared consumers silently depending on models
  • Data dependencies that can break systems without any code changes
Research Focus

Our research focuses on three key questions:

  1. How does including "black box" AI models degrade maintainability over time?
  2. Can we define new metrics - specifically a "Model Entanglement Score" - to quantify coupling?
  3. Do AI-enabled systems degrade 3 times faster than traditional systems?

How to Use
1. Upload Your Project

Choose from three collection methods:

  • Local Upload: Upload a ZIP file of your project
  • GitHub Collector: Clone a repository directly from GitHub
  • MLOps Platforms: Connect to Kubeflow, MLflow, BentoML, or Seldon Core
2. Analysis Process

The framework will automatically run all 6 tiers:

  • Tier 1: Scans files, detects languages, identifies services
  • Tier 2: Analyzes architecture, finds dependencies
  • Tier 3: Detects AI smells (direct calls, glue code, hidden consumers)
  • Tier 4: Calculates Model Entanglement Score (0-10)
  • Tier 5: Analyzes maintainability (churn, bugs, impact)
  • Tier 6: Validates research hypotheses
3. Results

View detailed results per tier and download a comprehensive PDF report.
